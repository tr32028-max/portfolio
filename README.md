# e-Portfolio | กิติชัย จอมนาวี (สแตมป์)

เว็บไซต์แฟ้มสะสมผลงานส่วนตัว นำเสนอประวัติ ความสนใจ ทักษะ ผลงานภาพยนตร์ กิจกรรม และเกียรติบัตรในรูปแบบหน้าเว็บที่รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

## เนื้อหาและความสามารถ

- แนะนำตัว ประวัติการศึกษา และทักษะ
- แสดงผลงานภาพยนตร์และกิจกรรม
- รวมเกียรติบัตรและช่องทางติดต่อ
- เมนูนำทางและหน้าต่างดูรายละเอียดกิจกรรม
- ออกแบบ Responsive พร้อมภาพประกอบที่ฝังอยู่ในไฟล์ HTML

## เทคโนโลยี

- HTML, CSS และ JavaScript แบบไม่ใช้ framework
- Google Fonts: Kanit และ Prompt
- GitHub Pages สำหรับเผยแพร่เว็บไซต์
